## v0.2.1 Release Highlights

* **Post-Render Quality Verification**: Automated FFmpeg scan reporting sustained black intervals and audio peaks near clipping.
* **Timeline Undo/Redo**: Up to 50 in-session history states covering trims, clip order, speed, and color adjustments.
* **Windows Packaging Hardening**: Fixed temp directory conflicts and enabled local Electron runtime cache for offline packaging.
