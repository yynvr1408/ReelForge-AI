**ReelForge AI v0.2.0** added audio intelligence (beat snapping & dialogue captions), LLM prompt adapters, and the in-app Updates system.

---

## v0.2.0 Release Highlights

* **Musical Beat Snapping**: Automatic snapping of cut points to musical tempo markers and rhythm bounds.
* **Dialogue Auto-Captions**: Rule-based subtitle generation aligned to dialogue segments.
* **In-App Updates Tab**: Added dedicated Updates page checking GitHub releases.
* **LLM Adapters**: Offline structured prompt adapters for local timeline planning.
