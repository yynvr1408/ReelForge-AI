---

## v0.2.2 Release Highlights

* **Creative Color Grading Presets**: Added 6 creative presets (Neutral, Golden Hour, Cinematic Teal, Vivid Pop, Vintage Film, Dramatic B&W) with "Grade to all" batch consistency.
* **Per-Clip Audio Controls**: Added volume gain sliders (-24 dB to +12 dB), 1-click mute, and audio fade in/fade out durations.
* **Expanded Export Presets**: Added 9:16 Vertical HD/Fast, 4:5 Portrait Feed, 16:9 Landscape HD, and 1:1 Square Feed.
* **Public Release Integration**: Integrated with the separate public releases repository for automated Squirrel packaging and publishing.
